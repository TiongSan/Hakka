使用與授權

非商業使用：本站的客語 TTS 透過 ivanusto/tw-hakka-tts 呼叫 FormoSpeech 客語 TTS 模型。該 Space 的程式碼中繼資料標示 MIT； 其使用的 FormoSpeech 四縣／海陸 TTS 模型 目前標示為 CC BY-NC 4.0，要求姓名標示且限制非商業使用。 本站因此將此發音功能限定為非商業教育、自學與研究試用。

資料傳送：按下合成時，輸入文字、腔調與必要參數會直接由你的瀏覽器送往 Hugging Face Space。 本站沒有自己的 TTS 後端，也不在本站伺服器保存合成內容；第三方服務仍可能依其政策處理網路連線資訊。 詳情請見 關於／授權與隱私。

API 診斷

MVP 會先用 Gradio 官方 JS Client 的 view_api() 讀取 Space 當下實際端點，再依參數名稱／標籤自動組 payload。若 Space 改版，這裡可以看到最新 API 結構。
